TABsucks 音乐分析工具 - UI排版与交互需求文档

1. 全局设计规范 (Global Design System)

视觉风格：暗黑模式 (Dark Mode) + 极简线框风。背景纯黑，容器和边框主要为白色实线，强调色/主按钮为亮蓝色（如 #5b65ff）。

字体排版：推荐使用JetBrains官方字体，文字全白。

页面大框架 (两栏布局)：

左侧边栏 (Sidebar)：固定宽度（约 200-240px），右侧有一条白色实线分割边框。

顶部：Logo 文字 "TABsucks"，下方带白色下划线分割。

中间：滚动列表，包含多个以白色细边框包裹的 "workshop" 矩形按钮。

底部：固定在一个蓝色胶囊形按钮 "new workshop"。

右侧主工作区 (Main Area)：占据剩余全部宽度，使用 Flex 纵向布局。

顶部导航栏：居中显示三个带白色边框的矩形指示器 [INPUT]、[SELECT]、[OUTPUT]。间距均等。

中间内容区：根据不同步骤动态切换（见下方 Tab 描述）。

底部操作栏：贴底放置，主要用于放置 previous 和 next 等蓝色胶囊导航按钮（分别靠左下角和右下角对齐）。

2. 各步骤 (Tab) 页面排版细节

Tab 1: INPUT (文件输入页)

中间内容区：绝对居中对齐 (Flex center)。

主要元素：两个横向并排的宽矩形按钮，白色边框，内部文字 "Upload audio file"。

底部操作栏：仅右下角有一个蓝色胶囊按钮 "next"。

Tab 2: SELECT (分离器与音轨选择)

特殊元素：右上角绝对定位一个带白色边框的矩形按钮 "MODEL"。

标题：上方居中文字提示 "select your seperator and tracks"。

中间内容区：一个 2行 x 3列 的网格布局 (Grid)，居中显示。

Grid 元素：6个正方形大按钮，白色边框，分别代表不同音轨 "Bass", "GUITAR", "VOCAL" (第一行), "KEYBOARD", "DRUM", "ELSE" (第二行)。

底部操作栏：左下角蓝色按钮 "previous"，右下角蓝色按钮 "next"。

Tab 3: SELECT (分析器配置)

标题：上方居中文字提示 "select your analyzers"。

中间内容区：一个 1行 x 3列 的网格布局，居中显示。

Grid 元素：3个正方形大按钮（样式同 Tab 2），文字为 "Bass", "GUITAR", "DRUM"。

交互说明/占位：在正方形按钮下方居中放置一段提示文字（"这里做成点击对应的乐器按钮，然后相应的乐器模块下面就出现一个选择条"），暗示此处的 UI 需要支持点击展开的交互。

底部操作栏：左下角蓝色按钮 "previous"，右下角蓝色按钮 "next"。

Tab 4: OUTPUT (时间轴与识别结果)

中间内容区 (Timeline Container)：一个大型的、带白色边框的容器，内部纵向排列多条音轨。

音轨行结构 (Track Row)：

左侧 (Track Label)：固定宽度的纵向分隔区，显示乐器名称（如 "BASS", "GT"）。

右侧 (Track Content)：占据剩余宽度，上下分为两层：

上层：显示音频波形图 (Waveform)。

下层：水平排列的和弦色块（圆角矩形，深蓝色底色），内部显示识别出的和弦字母（如 C, A, Fmaj）。

播放头 (Playhead)：一条贯穿所有音轨的垂直红色线条，指示当前播放位置。

底部操作栏 (特异化)：

左下角：蓝色按钮 "previous"。

右下角（播放控制区）：水平排列的自定义播放器控件。从左到右依次为：进度条（带圆形拖拽点） -> 时间显示 (如 0:27/4:15) -> 蓝色的圆形播放按钮 (▶) -> 播放倍速文字 (如 x2)。
